# Home HQ local adaptations

Public fork of [wesbos/photo-frame-dashboard](https://github.com/wesbos/photo-frame-dashboard).
The upstream MIT license and history are retained. Our F10 adaptations are reviewed
on separate branches and pull requests against this fork’s `main`.

The Android app lives in `dashboard/kiosk/`. HomeView Mini is a separate dashboard
in `BartoszWu/homelab`; no personal device settings, credentials, diagnostic dumps,
signing keys or built APKs belong in Git. See the kiosk README for opt-in setup,
local checks and rollback.
